## Como abrir localmente

Cada projeto tem seu proprio `index.html`. Para visualizar no navegador, abra o arquivo da pasta desejada ou use uma extensao como Live Server no VS Code.

Exemplo:

```text
7-steak-house/index.html
AutoConfianca/index.html
Botica/index.html
```
